# 🎨 UI/UX Designs

A collection of UI/UX design projects created using **Figma**, focusing on clean interfaces, visual consistency, typography, and user-friendly experiences.

---

## 📌 Projects

### 🎬 1. Movie Booking UI

A movie discovery and booking interface designed to provide users with an easy way to explore movies and view relevant movie information.

**Design Includes:**
- 🎥 Movie browsing interface
- 🔍 Movie categories and filters
- 🎬 Movie details
- 🌐 Language and format selection
- 👤 Navigation and profile interface

**Tool:** Figma
